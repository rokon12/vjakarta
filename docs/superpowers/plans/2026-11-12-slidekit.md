# Slidekit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A template repo, `slidekit`, from which a new talk's deck is written in one `deck.md` and built into one self-contained HTML page by the vfun/vjakarta engine.

**Architecture:** The engine, themes, checks and probe are copied from vjakarta after the Jakarta light plan is merged. New Node modules in `slides-src/lib/` turn `deck.md` into the same section markup and `notes.json` the engine already consumes (Markdown subset → layout renderers → build), and write the phone cue sheet from the same notes. The example deck is a dozen vjakarta slides converted to Markdown, covering every layout.

**Tech Stack:** Node 24 with `node:test` (no npm packages), Python 3 unittest for the existing Python checks, headless Chrome.

**Spec:** `docs/superpowers/specs/2026-11-12-slide-kit-design.md` (Part 2). Runs after `docs/superpowers/plans/2026-11-12-jakarta-light.md` is merged to vjakarta `main`.

### The `deck.md` format (decided in the spec; exact syntax decided here)

- The file starts with a header block (`---` line, `key: value` lines, `---` line) of deck settings: `theme` (default `jakarta-light`), `title` (browser tab and cue sheet), `minutes` (default `45`), `author` (optional).
- Each following slide is a header block, then a Markdown body. A slide with no keys may start with a bare `---`. Values split on the first `": "`; a value may contain colons. `---` inside a fenced code block is not a separator.
- Slide keys: `layout` (default `statement`), `id` (default: slug of the slide's first heading; a repeat gets `-2`, `-3`; an explicit duplicate `id` is a build error), `title` (navigation and cue-sheet title; default the first heading's text), `section` (section name; its key is the slug), `min` (minute mark), `kicker`, `source` (space-separated `<tag>:<path>` or bare `<path>`, as `data-source` today), `scene`, `args` (JSON), `height` (scene box px, default `654`), `steps` (for scene slides), `terminal` (on-screen command), `terminal-at` (click it appears on, default `1`), `terminal-until` (click it hides after; maps to `data-until`), `qr` (path of an SVG under `assets/`), `class` (extra classes on the section).
- Body Markdown: `#`, `##`, `###` headings; paragraphs; `**strong**`, `*em*`, `` `code` ``, `[text](url)`, `![alt](src)`; lists where `-` items show together and `+` items appear one per click (click numbers continue across the slide in order); `{.class}` at the end of a paragraph, heading or list item adds classes; fenced code with a language; a line starting with `<` starts a raw HTML block that runs to the next blank line and passes through untouched; everything else is escaped (`<`, `>`, `&`).
- In fenced code: `[[text]]` marks a highlighted span (`.hl`); a line starting with `+ ` is an added line (`.ln.add`) that appears on the next click, the marker removed; the code check compares the text with markers removed.
- Notes: everything after a line `???` up to the slide's end. `goal: …` sets the slide goal; a line `--` starts the next click (the first click is the slide's arrival); lines starting `tip: `, `more: `, `run: ` set that field of the current click; other lines join into its `say`. A slide may have at most `steps + 1` clicks (`steps` = the larger of its `data-steps` and its highest `data-step`); more is a build error.

## Review Focus

1. A `---` line inside a fenced code block, or a header value containing `: `, splits a slide or truncates a value. Pinned in Task 2.
2. `<`, `&` and generics such as `List<String>` in text or code are swallowed as HTML instead of shown. Pinned in Task 2.
3. Notes with more clicks than the slide has steps, or a `+` list on a scene slide, silently misalign the cue sheet with the slide. Pinned in Task 5.
4. Two slides whose first headings are the same produce duplicate ids and break navigation. Pinned in Task 4.
5. A talk length other than 45 minutes leaves the ruler, the "here" marker and the clock on a 45-minute scale. Pinned in Task 5.

**Interfaces:**
- Produces `markdown.mjs`:
